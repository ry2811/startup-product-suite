# Flowboard — Product case study

## Problem

Small startup teams lose context when tasks are scattered between chat, docs and heavyweight project-management tools.

## Product decision

Flowboard focuses on one high-frequency job: seeing sprint status and moving work forward. The board keeps metadata intentionally compact so users can scan it quickly.

## Implemented experience

- Four-stage sprint workflow with visible work-in-progress.
- Create-task modal with keyboard submission.
- One-click progression through workflow states.
- Responsive product shell and reusable design tokens.

## Role and stack

Product design, interaction design and frontend implementation using React, TypeScript, Vite and CSS.

## Suggested validation

Test with 5 product-team members and measure time-to-create-task, task findability and perceived board clarity.
