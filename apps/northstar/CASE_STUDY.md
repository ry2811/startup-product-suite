# Northstar — Product case study

## Problem

Early-stage teams often track many metrics without knowing which part of the acquisition-to-paid funnel needs attention.

## Product decision

Northstar groups revenue, activation, acquisition and conversion into a single decision-oriented overview instead of a generic chart collection.

## Implemented experience

- Period switching with recalculated KPI values.
- Responsive SVG revenue chart.
- Acquisition channel comparison.
- Visitor-to-paid conversion funnel.

## Role and stack

Dashboard UX, data visualization and frontend implementation using React, TypeScript, SVG and CSS.

## Suggested validation

Run comprehension testing with founders and growth specialists; measure time needed to identify the weakest funnel stage.
